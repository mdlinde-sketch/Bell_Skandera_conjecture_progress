# Bell–Skandera conjecture: candidate proofs in degrees 5 and 6

**Status: public research draft; not peer-reviewed.** The repository contains proposed computationally certified proofs for the degree-5 and degree-6 cases of the Bell–Skandera question: whether every positive-integer-coefficient real-rooted polynomial with constant term 1 is the face polynomial of a simplicial complex.

Read the [combined manuscript](paper/combined-degree-5-6.md) and reproduce the exact finite calculations with the verification programs below. **These results should not be cited as established theorems until independently checked by a specialist.** Their originality has not been conclusively established.

## Summary

Maclaurin's inequalities and a monotonic binomial-ratio bound restrict possible Kruskal–Katona failures to finitely many exceptional integer coefficients. Newton's inequalities then yield a provably bounded finite set of candidates. All remaining Kruskal–Katona violators have an explicitly negative Hermite moment-matrix principal determinant, ruling out real-rootedness.

| Degree | Newton-admissible cases checked | Kruskal–Katona violators | Violators with negative Hermite determinant |
| ---: | ---: | ---: | ---: |
| 5 | 125 | 6 | 6 |
| 6 | 4,445 | 22 | 22 |

## Reproduce

Python 3 (standard library only):

```bash
python verification/degree5_certificate.py
python verification/degree6_certificate.py
```

For two structurally different checks, install `sympy` and run:

```bash
python -m pip install -r requirements-verification.txt
python verification/degree5_independent.py
python verification/degree6_independent.py
```

GitHub Actions also runs all four scripts on every push.
